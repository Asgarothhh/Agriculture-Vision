# Документация базы данных системы анализа сельскохозяйственных угодий

Данная база данных спроектирована для обеспечения работы автоматизированной системы анализа геопространственных данных с использованием моделей машинного обучения (SegFormer и YOLO). База данных разработана на СУБД **PostgreSQL** с использованием ГИС-расширения **PostGIS**.

## Архитектурные принципы проектирования

1. **Третья нормальная форма (3NF):** Структура таблиц минимизирует избыточность данных и исключает аномалии модификации.
2. [cite_start]**Ролевой доступ (RBAC):** Реализовано разграничение прав пользователей через таблицы ролей для обеспечения авторизации и управления очередью обработки[cite: 6].
3. **Целостность данных:** Связи между таблицами защищены внешними ключами. При удалении родительского снимка (`images`) каскадно удаляются все связанные результаты распознавания (`ON DELETE CASCADE`), что предотвращает появление "мусорных" записей.
4. [cite_start]**ГИС-совместимость:** Пространственные данные (`Polygon`, `Point`) хранятся в нативных гео-типах данных PostGIS с поддержкой географической системы координат исходного снимка[cite: 12].

## Описание подсистем и таблиц

### 1. Подсистема управления доступом и заданиями
* [cite_start]**roles** — справочник ролей пользователей системы (Администратор, Агроном, Оператор)[cite: 6].
* [cite_start]**users** — учетные записи пользователей системы, обеспечивающие авторизацию[cite: 6].
* [cite_start]**processing_tasks** — очередь задач на обработку, фиксирующая статусы выполнения и историю запросов[cite: 6].

### 2. Модуль загрузки и предобработки данных
* **images** — метаданные загруженных снимков. Таблица поддерживает хранение информации о RGB, NIR и мультиспектральных каналах[cite: 9]. Включает результаты валидации координатной сетки (CRS), площади покрытия и признака целостности файла[cite: 10].

### 3. Справочники
* [cite_start]**object_classes** — единый реестр классов объектов (классы 1–4 для полигонов полей [cite: 3][cite_start], классы 5–6 для точечных объектов [cite: 4]).
* **models_registry** — реестр используемых в системе ML-моделей (архитектуры SegFormer и YOLO различных версий). Позволяет проводить аудит того, какая именно модель сформировала объект.

### 4. Подсистема результатов ML-обработки
* **polygons** — векторные границы полей (классы 1–4), распознанные моделью SegFormer[cite: 3, 12]. Содержит флаг `needs_manual_check`, который выставляется в `TRUE`, если уверенность классификатора ниже заданного порога[cite: 19].
* [cite_start]**crop_probabilities** — результаты классификации сельскохозяйственных культур внутри полигонов[cite: 5, 17]. [cite_start]Хранит полное распределение вероятностей по всем доступным классам культур, а не только класс-победитель[cite: 18].
* [cite_start]**point_objects** — координаты отдельно стоящих деревьев и столбов (классы 5–6), найденных моделью YOLO внутри или на периферии полей[cite: 4, 14]. [cite_start]Позволяет сохранять вычисленные моделью координаты точки и приблизительные значения радиуса и площади объекта[cite: 15].

## Инструкция по развертыванию

### Требования
* Установленный сервер **PostgreSQL** (версии 13 и выше).
* Установленное расширение **PostGIS**.

### Шаги по установке расширения PostGIS (на Windows)
Если при выполнении скрипта возникает ошибка отсутствия управляющего файла расширения (`postgis.control`), выполните следующие шаги:

1. Откройте меню «Пуск» на вашем компьютере, введите в строке поиска **Application Stack Builder** и запустите утилиту.
2. В выпадающем списке выберите вашу запущенную службу СУБД (например, *PostgreSQL 16 on port 5432*) и нажмите кнопку **Next (Далее)**.
3. Программа загрузит актуальный каталог приложений. Найдите и раскройте дерево категорий **Spatial Extensions** (Пространственные расширения).
4. Установите флажок напротив актуальной версии **PostGIS Bundle** (например, *PostGIS 3.4 Bundle*) и нажмите **Next**.
5. Укажите директорию для временного скачивания файлов и нажмите **Next**. После завершения загрузки автоматически откроется официальный мастер установки PostGIS.
6. В инсталляторе PostGIS нажимайте кнопки *Next* и *I Agree*. 
7. **Важно:** на одном из финальных шагов появится всплывающее диалоговое окно с вопросом: *"Do you want to create a spatially-enabled database?"* (Хотите ли вы создать готовую географическую базу данных?). Нажмите **Нет (No)**, так как целевую структуру мы развернем самостоятельно с помощью SQL-скрипта.
8. Дождитесь успешного окончания установки (Close). Компоненты PostGIS скопированы в системные папки PostgreSQL.
